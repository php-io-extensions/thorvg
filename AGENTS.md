# Agent guidance — php-io-extensions/thorvg

0. **Read [`.okf/index.md`](.okf/index.md) first**, then only the concepts the change touches. Durable facts go in `.okf` (update the concept, append `.okf/log.md`).
1. **The design spec:** [`docs/superpowers/specs/2026-11-13-thorvg-design.md`](docs/superpowers/specs/2026-11-13-thorvg-design.md). Its "Names and translations" lists every translation; there are no others.
2. **Bindings are 1:1 at ThorVG 1.1.3's C API** (tag `v1.1.3`, commit `589bc4120f2097fb1b135e552c2ef39f6581612b`): every `TVG_API` function in `thorvg_capi.h`, including the Lottie, GL and WebGPU ones, which answer ThorVG's own "not supported" in this build. Function, enum and constant names are the C names. No defaults, no composites.
3. **Upstream is copied unchanged** into `lib/thorvg/` (`inc/`, `src/`, `LICENSE`, `README.md`, `CONTRIBUTORS.md`), minus the folders this build does not compile: `src/loaders/lottie`, `src/renderer/gpu_engine`, `src/loaders/external_*`, `src/loaders/media/web`. Never edit it. `src/thorvg-config/config.h` is what meson would write for the module choice, and only ThorVG's sources see it (their rule in `config.m4` leaves PHP's include paths out, since PHP's `config.h` has the same name). A new ThorVG only from a new upstream tag: replace `lib/thorvg/`, diff `thorvg_capi.h` and the meson source lists, update the bindings, tests, `PHP_THORVG_UPSTREAM_COMMIT` and the version.
4. **Modules in:** CPU engine (NEON on arm64, AVX2 in the SIMD file on x86-64), partial rendering, threads, SVG, PNG, JPG, WebP, TTF/OTF, media (AVFoundation on macOS, no backend elsewhere), GIF saver, file IO. **Out, by Angel's choice (2026-11-13):** GL and WebGPU engines, Lottie.
5. **The stub is the declaration.** Every `ZEND_FUNCTION` is written out by hand, never made by a macro; shared checks go through `src/runtime.c`.
6. **Build.** `./install-macos.sh` into Homebrew `php@8.4` and `php@8.4-zts` (`zhp`). Pest: `php -d memory_limit=128M vendor/bin/pest` on both builds. After changing a check: `tools/sweep.php`. Gate a commit on the suite's exit code. Only `get_module` is exported (`nm -gU`).
7. **Version** is `PHP_THORVG_VERSION` in `php_thorvg.h`: 0.11.0, venusian/framework's 0.x line. `os-families`: linux, darwin.
